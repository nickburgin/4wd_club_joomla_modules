# Renew Subscriptions

### Task Scheduler plugin for Joomla to generate a new invoice for subscription renewals due.

Typical Use Case:
Consider a scenario where you users signing up for a period of time and the time has just expired, this scheduled task will identify the record and create a new one.

### How it works

You can set 
- frequency count, default is 1
- frequency type, default is DAYS

Compatibillity: Joomla 5+
