# Decisions Management (com_gadecisions)

> **Archived** — this extension is not in the maintained repository. Documentation is preserved from Glenn Arkell's website.

## Description

A Joomla component that helps organisations manage voting on motions and decisions. Members vote on motions via the front end; results are tracked in the back end.

## Creating a motion

When setting up a motion record, provide:

- Title
- Full explanation and content
- Associated user group (restricts voting to that group)
- Optional expiry date
- Whether a seconder is required
- Voting type: simple Yes/No, or custom multiple-choice (via a Radio/List custom field assigned in the Extra Info tab)

## Configuration options

| Option | Description |
|--------|-------------|
| Content display order | Whether motion content shows first or last on the front end |
| Scrutineer group | Optional user group designated as scrutineers |
