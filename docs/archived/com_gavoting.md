# Election Voting Management (com_gavoting)

> **Archived** — this extension is not in the maintained repository. Documentation is preserved from Glenn Arkell's website.

## Description

A system designed to facilitate online voting for committee member elections within clubs, groups, and charities. Manages nominations, voting procedures, and motion voting.

## Key features

- Online nomination and voting
- Proxy voting with multiple configuration options
- Motion voting for members
- User group-based access restrictions
- Regional bundling of users
- Multi-user account linking to single membership records
- Automatic or manual nomination acceptance
- Vote counting and results display
- Guided tours

## Configuration options

- Election date management (nominations close, voting periods)
- Term limits for incumbents
- Member restriction controls by user group
- Proxy voting type selection
- Motion-specific settings with colour highlighting
- Custom club/group rules display
- Permission controls for nominating and voting
