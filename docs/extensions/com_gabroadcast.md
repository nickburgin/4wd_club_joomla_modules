# Broadcast Management System (com_gabroadcast)

**Current version:** 4.3.3

## Description

A straightforward component that permits designated users to distribute broadcast emails to all registered website users. The system uses phpMail for email delivery through your website.

## Installation

Install `com_gabroadcast` via **Joomla Admin → Extensions → Install → Upload Package File**.

## Features

- Send broadcast emails to registered users
- Role-based access control — only designated users can send
- Integration with phpMail

## Important considerations

**Email service limitations:** Some hosting providers restrict or limit email sending from websites. You may encounter delivery issues or need to ask your provider to lift sending restrictions on your account.
