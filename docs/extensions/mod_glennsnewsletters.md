# Newsletter Listing (mod_glennsnewsletters)

**Current version:** 4.4

> No upstream source is available for this module. The copy in this repository was extracted from the live site and is the only known surviving version.

## Description

Displays files from a designated media folder as clickable links. Underscores in filenames are automatically converted to spaces. Useful for presenting a newsletter archive where newsletters are uploaded as PDFs to a media folder.

## Installation

Install `mod_glennsnewsletters` via **Joomla Admin → Extensions → Install → Upload Package File**, then configure it via **Joomla Admin → Extensions → Modules**.

## Configuration options

| Parameter | Description |
|-----------|-------------|
| Folder | Path relative to the Joomla media folder |
| File type filter | Show only files matching a specified extension (e.g. `pdf`) |
| Sort order | Customise file arrangement |
| Display height | Optional fixed-height scrollable area in pixels |
