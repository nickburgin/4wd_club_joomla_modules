# Track Log Management System (com_gatracklog)

**Current version:** 4.2.0

## Description

A component for managing 4WD track logs, providing storage and organisation of track data including names, file formats, and log records.

## Installation

Install `com_gatracklog` via **Joomla Admin → Extensions → Install → Upload Package File**.
