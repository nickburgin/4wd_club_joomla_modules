# For Sale System (com_gaforsale)

**Current version:** 4.2.2

## Description

A straightforward component that enables registered members to share and upload details about items they wish to sell.

## Installation

Install `com_gaforsale` via **Joomla Admin → Extensions → Install → Upload Package File**.

## Features

- Members can post items for sale with images
- Items can be marked as sold, removing them from active listings
- Registration required — only logged-in members can post
