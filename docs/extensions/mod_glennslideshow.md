# Glenn's Slideshow (mod_glennslideshow)

**Current version:** 4.7

> No upstream source is available for this module. The copy in this repository was extracted from the live site and is the only known surviving version.

## Description

A slideshow module that uses Bootstrap's carousel framework. Images can be sourced from a media folder or from articles in a chosen category.

> Requires Joomla 4 or later. Does not work on Joomla 3.

## Installation

Install `mod_glennslideshow` via **Joomla Admin → Extensions → Install → Upload Package File**, then configure it via **Joomla Admin → Extensions → Modules**.

## Configuration options

### Source
- **Mode:** folder or article category
- **Folder / Category:** select from dropdown

### Display
- Transition type
- Cycle time
- File type filtering by extension

### Navigation & appearance
- Show/hide navigation icons and indicators
- Adjust display dimensions
- Custom CSS classes
- Heading tag

### Captions
- Show/hide captions
- Captions auto-generate from filenames (underscores converted to spaces)
