# For Sale Module (mod_gaforsale)

**Current version:** 3.0.09

> No upstream source is available for this module. The copy in this repository was extracted from the live site and is the only known surviving version.

## Description

Front-end module companion to [com_gaforsale](com_gaforsale.md). Displays a summary or listing of current for-sale items in a module position.

## Installation

Install `mod_gaforsale` via **Joomla Admin → Extensions → Install → Upload Package File**, then assign it to a module position via **Joomla Admin → Extensions → Modules**.
