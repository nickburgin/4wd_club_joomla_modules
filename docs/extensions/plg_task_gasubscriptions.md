# Subscriptions Task Plugin (plg_task_gasubscriptions)

**Part of:** `pkg_gausers`  
**Current version:** 5.3

## Description

A Joomla scheduled task plugin that automates membership subscription renewal notifications. Installed as part of the [User Membership Package](com_gausers.md).

## Setup

After installing `pkg_gausers`, configure the scheduled task via **Joomla Admin → System → Scheduled Tasks**.
