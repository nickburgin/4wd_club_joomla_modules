# 4WD Club Joomla Extensions

Documentation for a suite of Joomla 5 extensions designed for 4WD and community clubs. Originally developed by Glenn Arkell; now maintained as an open-source fork.

> **For developers:** source code, build tooling, and contribution notes live in the [GitHub repository](https://github.com/nickburgin/4wd_club_joomla_modules).

## Available extensions

### Packages *(recommended — install these)*

Installing a package installs all constituent extensions together in the correct order, including guided tours.

| Package | What it provides |
|---------|-----------------|
| [Finance Package](extensions/com_gafinance.md) | Club finance management — transactions, accounts, invoicing, reporting |
| [Trip Management Package](extensions/com_gatripsys.md) | Trip planning, bookings, attendee management, and cost tracking |
| [User Membership Package](extensions/com_gausers.md) | Member records, membership invoicing, and subscription automation |
| [Calendar Events Package](extensions/com_gacalevents.md) | Club calendar and event attendance |

### Standalone extensions

| Extension | Description |
|-----------|-------------|
| [Broadcast Management](extensions/com_gabroadcast.md) | Send broadcast emails to registered site users |
| [For Sale](extensions/com_gaforsale.md) | Member-to-member classifieds listing |
| [Merchandise](extensions/com_gamerchandise.md) | Club merchandise catalogue and sales |
| [Track Log](extensions/com_gatracklog.md) | 4WD track log management |
| [Slideshow](extensions/mod_glennslideshow.md) | Bootstrap carousel from a media folder or article category |
| [Newsletter Listing](extensions/mod_glennsnewsletters.md) | Display files from a media folder as a newsletter archive |
| [4WD User Profile Plugin](extensions/plg_user_profileb4wdc.md) | Adds 4WD-club-specific fields to Joomla user profiles |
